# بازارگاه اینترنتی بین‌المللی چندفروشنده‌ای (Bazargah Marketplace)

راهکار بومی و قدرتمند توسعه بازارگاه اینترنتی بین‌المللی چندفروشنده‌ای (Multi-vendor E-commerce Marketplace) الهام گرفته از پلتفرم‌های بزرگی همچون Amazon، پیاده‌سازی شده با Next.js/Hono، TypeScript، React، Tailwind CSS و SQLite در محیط Cloudflare Durable Objects.

---

## 🚀 ویژگی‌ها و امکانات اصلی

### ۱. بخش عمومی و کاتالوگ محصولات
- **صفحه اصلی مدرن:** هدر حرفه‌ای با جستجوی لحظه‌ای، بنرهای تبلیغاتی، منوی دسته‌بندی‌ها، محصولات ویژه و فروشندگان برتر.
- **کاتالوگ پیشرفته:** قابلیت فیلتر بر اساس دسته‌بندی، مرتب‌سازی براساس قیمت و جدیدترین‌ها، جستجوی زنده در نام و توضیحات.
- **صفحه اختصاصی کالا:** گالری تصاویر، جدول مشخصات فنی، مشخصات فروشنده، برچسب موجودی انبار، سیستم نظرات و امتیازدهی خریداران.
- **سبد خرید و محاسبه سمت سرور:** محاسبه خودکار قیمت، تخفیف، هزینه ارسال و بررسی موجودی انبار به‌صورت کاملاً امن در سمت سرور.

### ۲. درگاه پرداخت شبیه‌سازی‌شده (Mock Gateway)
- شبیه‌سازی کامل فرایند پرداخت شتاب.
- ثبت لحظه‌ای سفارش، کسر خودکار موجودی انبار محصولات، محاسبه کمیسیون بازارگاه و واریز خالص مبلغ فروش به دفتر مالی فروشنده (Seller Ledger).

### ۳. پنل فروشندگان (Seller Panel)
- ایجاد و مدیریت فروشگاه، مشاهده نرخ کمیسیون اختصاصی.
- افزودن، ویرایش و مدیریت قیمت و موجودی کالاها.
- مدیریت سفارش‌های دریافتی و تغییر وضعیت مرسوله‌ها (در حال پردازش، ارسال شده، تحویل داده شده).
- دفتر ثبت تراکنش‌های مالی (Ledger)، مشاهده موجودی قابل تسویه و ارسال درخواست واریز (Payout).

### ۴. پنل مدیریت کل سیستم (Admin Panel)
- **داشبورد آمار کلیدی:** نمایش GMV (حجم کل معاملات)، مجموع کمیسیون کسب‌شده بازارگاه، تعداد کاربران، تعداد فروشگاه‌ها و سفارش‌ها.
- **مدیریت فروشگاه‌ها:** تأیید یا رد درخواست فروشندگی، تغییر نرخ کمیسیون متغیر هر فروشگاه.
- **مدیریت کاربران و نقش‌ها:** کنترل سطوح دسترسی (ADMIN, SELLER, CUSTOMER).
- **بازنشانی داده‌ها (Seed Data):** امکان بازنشانی و بارگذاری مجدد داده‌های نمونه بازارگاه با یک کلیک.

## 🛠️ فناوری‌های استفاده شده

- **فرانت‌اند:** React 18, Tailwind CSS, Lucide Icons, RTL / Vazirmatn Persian Font
- **بک‌اند & API:** Hono Framework, Cloudflare Workers / Durable Object
- **دیتابیس:** SQLite متصل به Durable Object Storage
- **امنیت:** هش رمز عبور با الگوریتم Web Crypto SHA-256، نشست‌های توکن‌دار، کنترل دسترسی براساس نقش (RBAC)، اعتبارسنجی مجدد تمامی قیمت‌ها و تخفیف‌ها در سمت سرور.
