# پروژه بازارگاه اینترنتی چندفروشنده‌ای شاهکار (Shahkar Marketplace)

سیستم هوشمند مدیریت و تولید اطلاعات محصولات و بازارگاه چندفروشنده‌ای بین‌المللی الهام‌گرفته از الگوهای بزرگی همچون علی‌بابا و آمازون.

---

## 🚀 قابلیت‌های کلیدی سیستم مدیریت محصولات شاهکار (توسعه پرامپت شماره ۲)

### ۱. مدیریت کامل اطلاعات محصولات
- **شناسه‌های ساختاریافته:** شناسه یکتا، URL slug، کد انبارداری SKU، کد بارکد بین‌المللی.
- **مشخصات فنی و متغیرها:** مشخصات فنی کلید-مقداری، برند، متغیرهای کالا (رنگ، سایز)، وزن، ابعاد، شرایط ارسال.
- **چندتصویری و عکس اصلی:** مدیریت لیست تصاویر کالا، تعیین تصویر اصلی (`main_image_index`) و متن‌های جایگزین alt.
- **بهینه‌سازی سئو:** تولید و ویرایش عنوان سئو، متاتوضیحات و کلمات کلیدی.

### ۲. سیستم ورود گروهی کالاها (Bulk CSV Import)
- **دانلود قالب نمونه CSV:** امکان دانلود الگوی استاندارد شامل ستون‌های لازم.
- **پیش‌نمایش و اعتبارسنجی خط‌به‌خط:** بررسی اعتبار قیمت‌ها، دسته‌بندی‌ها، موجودی انبار و شناسه SKU.
- **گزارش خطا همراه با شماره سطر:** نمایش دقیق سطور دارای اشکال یا تکراری.
- **ثبت تراکنشی محصولات:** ثبت یکباره کالاهای معتبر در پایگاه داده و ایجاد گزارش کار در `bulk_import_jobs`.

### ۳. دستیار هوش مصنوعی و تولید محتوا (AI Content Assistant)
- **پیشنهاد عنوان هوشمند:** پیشنهاد ۳ عنوان جذاب و استاندارد بر اساس مشخصات کالا.
- **تولید توضیحات مارکتینگ و فنی:** ساخت خلاصه کالا و توضیحات جامع بخش‌بندی‌شده.
- **استخراج مشخصات فنی:** تبدیل متون غیرساختاریافته به جدول مشخصات ساختاریافته.
- **ارزیابی و پایش کیفیت کالا (AI Quality Audit):** محاسبه امتیاز کیفیت کالا (۰ تا ۱۰۰)، کشف نقص‌های اطلاعاتی و ارائه توصیه.
- **موتور پشتیبان محلی (Persian Rule-Based Fallback Engine):** تضمین ۱۰۰٪ عدم قطعی برنامه حتی در صورت نبود کلید API خارجی.

### ۴. گردش کار تأیید و انتشار (Workflow Queue)
- ورود کالاها به صف بررسی مدیر ارشد (`PENDING_APPROVAL`).
- قابلیت تأیید و انتشار (`APPROVED`) یا رد کالا همراه با دلیل (`REJECTED`).
- عدم نمایش کالاهای غیرمجاز در کاتالوگ عمومی خریداران.
