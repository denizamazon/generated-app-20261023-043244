# مستند پایگاه داده و مدل‌های موجودیت (Database Schema)

پایگاه داده پروژه بر پایه SQLite توسعه یافته و شامل جداول زیر می‌باشد:

### ۱. جدول کاربران (`users`)
- `id`: شناسه یکتا کاربر (`usr_...`)
- `full_name`: نام و نام خانوادگی
- `email`: پست الکترونیکی (یکتا)
- `password_hash`: هش کلمه عبور
- `role`: نقش کاربر (`ADMIN` | `SELLER` | `CUSTOMER`)
- `status`: وضعیت حساب (`ACTIVE` | `BLOCKED`)
- `phone`: شماره تلفن
- `created_at`: زمان ثبت‌نام (مهر زمانی)

### ۲. جدول فروشگاه‌ها (`stores`)
- `id`: شناسه یکتا فروشگاه (`str_...`)
- `user_id`: کلید خارجی به جدول `users`
- `store_name`: نام تجاری فروشگاه
- `slug`: شناسه یکتای آدرس وب
- `commission_rate`: نرخ کمیسیون اختصاصی بازارگاه (مثلاً ۵.۰ برای ۵٪)
- `balance`: موجودی قابل تسویه فروشنده (تومان)
- `total_sales`: مجموع کل فروش تاریخی

### ۳. جدول محصولات (`products`)
- `id`: شناسه یکتا محصول (`prd_...`)
- `store_id`: شناسه فروشگاه عرضه‌کننده
- `category_id`: شناسه دسته‌بندی
- `title`: عنوان محصول
- `price`: قیمت اصلی (تومان)
- `discount_price`: قیمت تخفیف‌دار
- `stock`: تعداد موجودی واقعی انبار
- `status`: وضعیت انتشار (`APPROVED` | `PENDING` | `DRAFT`)

### ۴. جدول سفارشات (`orders`) و اقلام سفارش (`order_items`)
- ذخیره‌سازی اطلاعات کامل خرید شامل آدرس ارسال، مبلغ کل، تخفیف، کمیسیون کسر شده و سهم پرداختی به هر فروشنده به تفکیک اقلام سفارش.

### ۵. جدول دفتر مالی فروشندگان (`seller_ledger`)
- ثبت شفاف تمام رکوردهای مالی شامل فروش، کمیسیون، واریزی و مرجوعی‌ها.
