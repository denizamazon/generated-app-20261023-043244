# مستند معماری فنی سیستم بازارگاه اینترنتی بین‌المللی

## ۱. مرور کلی معماری (High-Level Architecture)

این سیستم بر اساس معماری یکپارچه ماژولار (Modular Monolith) و سرویس‌دهی لبه (Edge Computing) طراحی شده است.

### اجزای اصلی:
1. **لایه فرانت‌اند (Client App):**
   - توسعه داده شده با React 18 و Tailwind CSS در قالب طراحی کاملاً واکنش‌گرا و راست‌چین (RTL).
   - مدیریت حالت محلی برای سبد خرید، آدرس‌ها، نشست کاربر و حالت‌های مختلف نمایش.
   - ارتباط با لایه API از طریق متد استاندارد `fetch` با ارسال توکن‌های احراز هویت.

2. **لایه سرویس‌دهنده و API (Server Engine):**
   - پیاده‌سازی شده با فریم‌ورک سبک Hono روی Cloudflare Durable Object Class (`App`).
   - ارائه API RESTful کامل شامل احراز هویت، کاتالوگ، فروشندگان، سبد خرید، سفارشات، مالی و مدیریت.

3. **لایه پایگاه داده (Persistence Layer):**
   - پایگاه داده SQLite به‌صورت تعبیه‌شده در Cloudflare Durable Object Storage (`this.ctx.storage.sql`).
   - عدم وابستگی به سرویس‌های خارجی سنگین و سرعت بالای کوئری‌ها در پاسخگویی به درخواست‌ها.

---

## ۲. امنیت و احراز هویت (Security & Auth)

- **رمزنگاری کلمات عبور:** کلمات عبور پیش از ذخیره‌سازی در دیتابیس با الگوریتم متقاطع Web Crypto SHA-256 ترکیب با Salt اختصاصی هش می‌شوند.
- **ارزیابی قیمت‌ها در سمت سرور:** مرورگر فقط لیست محصولات و تعداد را ارسال می‌کند؛ تمام محاسبات قیمت کالا، تخفیف، هزینه ارسال و موجودی انبار در سمت سرور و با شروع تراکنش مجدداً بررسی می‌شود.
- **محدودسازی دسترسی (RBAC):** نقش‌های کاربر شامل `ADMIN` (مدیر کل)، `SELLER` (فروشنده) و `CUSTOMER` (خریدار) تفکیک شده‌اند. فروشنده فقط امکان ویرایش محصولات و سفارشات مربوط به فروشگاه خود را دارد.
