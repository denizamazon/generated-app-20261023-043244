# مستند تست و کنترل کیفیت بازارگاه (Testing Guide)

این پروژه شامل تست‌های یکپارچه‌سازی و واحد تعبیه‌شده در سمت سرور است که از طریق API و فرانت‌اند قابل اجرا می‌باشد.

## ۱. سناریوهای تست پوشش داده شده:

۱. **تست دسته‌بندی‌های پایه:** صحت بارگذاری و تعداد دسته‌های استاندارد کاتالوگ.
۲. **تست قیمت و موجودی:** صحت خواندن قیمت کالا و موجودی مثبت انبار.
۳. **تست فرمول کمیسیون:** صحت کسر ۵٪ کمیسیون بازارگاه و واریز ۹۵٪ مبلغ فروش به حساب فروشنده.
۴. **تست کدهای تخفیف:** سنجش اعمال صحیح کد تخفیف `BAZAR2026` و فعال بودن آن.
۵. **تست کاربر ارشد مدیریت:** بررسی حضور حساب مدیر کل سیستم (`admin@bazargah.ir`).

## ۲. نحوه اجرای تست‌ها:

- **از طریق رابط کاربری:** روی دکمه «سنجش سلامت و تست‌های سیستم» در هدر یا فوتر سایت کلیک کنید.
- **از طریق API:** درخواست `GET /api/tests/run` را ارسال کنید.
